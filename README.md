# game-sea-battle

Морской бой: режим против бота и сетевой режим (комнаты по коду, быстрый поиск).
Node.js + Express + WebSocket, клиент на canvas без сборщика. Подготовлено к публикации в Яндекс Играх.

## Запуск

```bash
npm install
npm start
```

Открыть <http://localhost:3000>.

- `npm run dev` — запуск с автоперезагрузкой (`--watch`).
- `npm test` — юнит-тесты правил (`node --test`).
- `npm run check` — синтаксическая проверка всех JS/MJS.

`.env` не обязателен, значения по умолчанию указаны в `.env.example`.

## Игра по внутренней сети

Сервер слушает `0.0.0.0`, поэтому доступен в сети без дополнительной настройки.

1. Узнать свой адрес в сети:
   ```bash
   ipconfig getifaddr en0     # macOS
   ```
2. Сосед открывает в браузере `http://<ваш-адрес>:3000` — например `http://10.54.203.17:3000`.
3. Оба выбирают «Играть по сети», затем: один жмёт «Создать комнату» и диктует 5-символьный код,
   второй вводит его и жмёт «Войти». Либо оба жмут «Быстрый поиск».

Если соединение не устанавливается — проверьте, что оба в одной подсети и что файрвол не блокирует порт 3000.

Приватные адреса (`10.x`, `172.16-31.x`, `192.168.x`, `127.x`, `169.254.x`, `*.local`) разрешены
только при `NODE_ENV=development`. В `production` список origins задаётся переменной `ALLOWED_ORIGINS`.

## Структура

```
server.mjs               Express (статика, /healthz) + WebSocket-сервер, комнаты и сессии
public/index.html        разметка экранов
public/game.js           клиент: отрисовка canvas, бот, сетевой режим
public/platform.js       обёртка над Яндекс SDK (реклама, фуллскрин), работает и без SDK
public/config.js         рантайм-конфиг: serverUrl, частота рекламы
public/shared/rules.mjs  общие правила: флот, applyAttack, isFleetDestroyed (клиент + сервер)
tests/rules.test.mjs     юнит-тесты правил
```

## Для публикации в Яндекс Играх

1. Задеплоить за HTTPS, вписать публичный адрес в `public/config.js`:
   ```js
   serverUrl: "wss://game.example.ru/ws"
   ```
2. `NODE_ENV=production`, в `ALLOWED_ORIGINS` добавить адрес превью и домены Яндекса.
3. Комнаты хранятся в памяти процесса — при нескольких инстансах нужен внешний общий стор (Redis)
   либо sticky sessions.

Подробности по архитектуре, протоколу WS и принятым решениям — в `.opencode/`.
